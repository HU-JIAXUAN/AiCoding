# 完成判断

本表是后续模型实现的检查范围，不是本轮已经取得的证据。文档架构整理只检查文档、目录和一致性。

| 实现范围 | 最小证据 |
|---|---|
| 基础积木/电机 | 单位、方向、状态与复位，必要的独立数值/开环检查 |
| 电流闭环 | 可重复的阶跃/限制恢复场景，明确参数和日志；早期代码生成探路 |
| 工程三环 | 共同场景、采样/执行延迟、约束协作与指标 |
| 算法扩展 | 相同对象/工况/约束下的基线比较，适用范围与成本 |
| 目标验证 | SIL、对应 C2000 构建/PIL 各自记录，不因另一块板通过而继承 |
| 实机声明 | 对应板卡的 ADC/PWM/反馈、时间与实际电机证据 |

失败保留场景、配置、原因和复现方法。阈值在评价前依据设计目标/基线确定，不能看到结果后随意放宽。
