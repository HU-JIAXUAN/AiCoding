# ADR-0001：采用契约优先的可组合架构

- 状态：Accepted（规划基线）
- 日期：2026-11-07

## 背景
单体 Simulink FOC 模型不利于替换电机、控制算法和逆变器，也不利于测试与嵌入式部署。

## 决策
小算法由 Library 管理，大模型由 Model Reference 管理，切换点使用 Variant；Bus/数据字典描述标准接口，配置层驱动实验，Plant 与可部署控制器明确分离。

## 权衡
优点：隔离变化、测试复用、扩展性和追溯性较强。代价：初期接口/参数规范工作多，Model Reference 和变体可能增加编译管理复杂度。按当前分步计划从最小电流闭环逐步扩展，避免过度设计。两个 C2000 目标与当前实施排序见 [ADR-0002](ADR-0002-targets-and-workflow.md)。
