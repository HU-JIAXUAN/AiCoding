# ADR-0002：共用控制核与两个 C2000 目标

- 日期：2026-11-07。
- 状态：已确认架构整理范围；具体模型与硬件配置尚未实现。
- 依据：用户明确已有 P650 LaunchPad，后续使用自制 F28388D，要求按推荐方案整理草稿并保持简单分步计划。

## 决定

采用可读控制核 + 分级 Plant 路线。以控制核、Plant、采样/执行适配、实验/分析四个主要边界组织；P650 LaunchPad 为首个目标，自制 F28388D 为后续目标，均先以 CPU1 为基线。

共用算法、接口、工况与指标；两板分别保存配置与外设适配。目录沿用现有职责，只增加两个目标适配位置。小组件优先 Library/Subsystem，大组件与真实替换点按需采用 Model Reference/Variant。

计划按步骤列出工作项，不安排每日课程。本轮只整理文档、导航和目录；具体模型、字典、Project、运行脚本及目标工程在后续步骤实现。

## 暂未决定

首个电机/功率板/反馈、采样率与具体引脚、自制板原理图/既有固件，以及最终外设装配方式。它们不阻塞本轮架构整理，进入相应步骤时再核对。

本 ADR 补充 ADR-0001，并以当前[建设计划](../plans/IMPLEMENTATION_PLAN.md)取代原 P0–P3 实施排序。当前决策与计划在本工程内维护，不依赖已清理的外部草稿目录。
