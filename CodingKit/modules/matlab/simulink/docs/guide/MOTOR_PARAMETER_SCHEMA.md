# 电机参数字段模板

| 字段名 | 单位 | 要求 |
|---|---|---|
| `Rs_Ohm` | Ω | 正数；记录测试温度 |
| `Ld_H`, `Lq_H` | H | 正数，说明电角度和 d/q 方向 |
| `flux_Wb` | Wb | 永磁磁链定义与变换归一化一致 |
| `polePairs` | 1 | 正整数 |
| `J_kgm2` | kg·m² | 正数，说明电机轴/负载是否折算 |
| `B_Nms` | N·m·s/rad | 非负，说明模型依据 |
| `thetaOffset_rad` | rad | 电角度偏置及校准策略 |

禁止编造具体电机数值。首个电机的实际参数由用户或可核对来源提供后填写；教材凸极参数与真实 SPMSM 分开记录。
