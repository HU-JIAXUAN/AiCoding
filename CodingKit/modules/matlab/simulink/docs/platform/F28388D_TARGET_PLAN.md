# 自制 F28388D 目标计划

角色：后续自制硬件目标。复用已在仿真和 P650 上验证的控制核，重新建立板级配置和目标证据。

## 接入边界

先以 CPU1 执行控制，实际接入在对应的 model 实机装配模块中实现，开始接入时再建立模块。若已有 BSP/ISR，优先评估导出控制核后接入；未确认固件细节前，不固定整机生成或具体外设分工。

CPU2、CLA、CM 根据真实任务再分配；不默认引入通信、OTA 或多核框架。反馈接口可以是编码器/Hall/其他方式，BiSS 只是后续可能项，不因历史项目而成为本平台的必要依赖。

## 自制板必须明确的差异

| 项目 | 接入时核对 |
|---|---|
| 硬件身份 | 器件/封装、原理图修订、时钟、启动与调试连接 |
| 功率与反馈 | PWM 极性/死区、ADC 通道/比例/offset、传感器方向/零位与有效性 |
| 资源所有权 | 外设初始化、ADC ISR、PWM 提交和故障禁能由模型或 BSP 中的唯一一方负责 |
| 执行时序 | PWM 事件 → ADC → 反馈对齐 → 控制核 → shadow 写入/生效，记录实际 deadline |
| 构建与证据 | F28388D 自己的链接/编译配置、数值对照、板级测量与实物结果 |

芯片被 Blockset 支持，不等于自制板已经被验证。不能继承 P650 的外设映射、二进制或时间结论；控制算法和共同工况继续复用。
