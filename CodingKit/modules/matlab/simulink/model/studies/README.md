# 学习与复现

本目录用于文章学习、论文复现和第三方示例分析，当前暂无学习模块。

开始具体复现时，按功能创建独立目录，保留 `README.md`、`src/`、`parameter/`、`build_process/`、`waveform_analysis/`、`ref/` 和 `docs/`。记录资料来源、运行方法、参数和验证结果；模型放在所属模块的 `src/`，参考资料放在 `ref/`。

可直接运行的复现模型使用普通 `.slx`；提炼出的共用积木在 [lib](../lib/README.md) 中维护，完整应用在 [app_models](../app_models/README.md) 中维护。
