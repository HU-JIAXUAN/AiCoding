## 范围和指标窗口

验证入口定义18项物理工况，实际执行结果以[指标](hybrid_metrics.json)和[核对记录](hybrid_verification.json)为准。单次选择执行与完整覆盖分别记录，分批数据只在模型和源文件指纹一致、工况并集完整且无重复时合并。

默认高速检查为.95–1.25 s，**包含.9 s负载阶跃后的恢复过程**；低速检查为末.2 s。禁能重启和反转工况另有明确检查窗口，保存在每项记录的high_window。演示验收使用机械速度RMS<.5 rad/s、角RMS<.08 rad、原始dq电流误差RMS<.3 A，并检查有效比例、权重、注入及激活期间角峰值。阈值与实际值都保留，不把动态窗口RMS写成稳态精度。

原始dq电流包含HFI纹波。当前默认工况高速撤除HFI后的角RMS约0.0024523 rad；低速恢复后约0.0195294 rad，原始dq电流RMS约0.1355710 A。高速速度误差RMS约0.145965 rad/s，低速末段约0.0003022 rad/s。首次控制接通96.4 ms，含完整位置资格后的融合连续确认。完整结果以JSON逐项值为准。

本页高低速指观测器使用区间。4极对数下，40–60电角rad/s对应10–15机械rad/s；默认最高100电角rad/s没有进入48 V电机的弱磁区。无位置弱磁另行组装，不以本次EEMF接管代替弱磁验证。

## 工况覆盖

| 工况组 | 检查内容 |
|---|---|
| 正向、反向、相反初始磁极、改变高速停留时间 | 由实际电流完成初始极性；低→高→低及真实π分支重接 |
| 12位ADC/噪声、执行延迟、对齐采样延迟 | 作用电压/采样年龄、在线资格和物理跟随；误差包含所选数据年龄，不声称已补偿全部延迟 |
| 半实际执行电压、EEMF Rs偏差 | 观察器继续消费真实执行支路，控制积分补足执行比例；只覆盖记录中的参数失配 |
| 重叠区基波短缺样 | HFI已合格时回退，恢复基波需重新连续资格，控制不退出 |
| 高速持续基波丢失、低速来源失效后降至零速 | 没有可信来源时有限时间预测，然后Fusion/App按预期退出 |
| ADC电流故障、探针阶段复位、禁能重启 | 电流保护锁存、状态清除及Profile重新爬升 |
| 跨零反转 | HFI承担零低速，方向保持状态由估速更新，负向基波重新取得资格 |
| 采样年龄未对齐、无磁饱和极性特征 | 分别应由探针或极性阶段拒绝，不能放行电流控制 |

改变高速停留时间的物理工况已经出现相反的HFI轴线分支，融合额外π标志为1；这个分支来自实际对象与HFI重新跟踪，没有向观测器人为塞入真实角度或π误差。未完成分支确认前保持EEMF控制，恢复后最终角仍接近真实角。

## 读图与状态衔接

保存[往返](hybrid_round_trip.svg)、[原始纹波](hybrid_ripple.svg)、[π分支恢复](hybrid_branch_return.svg)、[故障](hybrid_faults.svg)和[反转](hybrid_reversal.svg)图，同名PNG用于预览。速度/权重概览可抽取1 ms点；相位、电流、转矩及局部纹波保留原50 μs采样，避免将10 kHz载波抽成虚假的直流偏差。

`hybrid_transition_metrics.json`从完整记录中额外分析保持电流控制期间的权重、注入和π标志变化，在前后1 ms窗口统计电流/转矩误差与定子固定坐标电压变化。这里使用相邻两拍平均抑制刻意注入的10 kHz分量；它是后处理指标，不替代原始波形，也不把故障停机归零当作普通融合衔接。全量记录同时核对速度反馈确实来自融合估速、电流Park确实使用对应采样年龄的ADC电流与融合角。

默认往返的上述交接窗口内，两拍平均后的电流误差峰值为0.0109291 A、转矩误差峰值0.00221203 N·m，固定定子坐标电压相邻步差峰值0.0316296 V。它们是指定工况的观测统计，不外推为硬件或所有工况的门限。

电流PI继续显式转移坐标状态：相邻融合角减去按基准速度推进的角度得到deltaExtra，送FrameTrackingPI。原始积分、比例和FF历史按该额外角变化处理；不是仅在Scope叠加两条角度曲线。实际作用电压、限压/回算和三相占空比仍由共用VoltageStage产生。

## 速度环失败与修正

原自然频率20 rad/s的速度环在禁能重启工况高速窗口.8–.9 s发生爬升结束后的超调，速度误差RMS为.638637 rad/s；没有观测失锁或App故障。将本App自然频率改为30 rad/s，由J/B/Kt重新计算PI后，同一窗口误差RMS降至.317358 rad/s。保持原.5 rad/s门限、输入、求解步长和检查窗口，全部18项在新配置下重跑。原始失败与修正记录保存在`hybrid_speed_tuning.mat`（运行验证后生成）和[JSON](hybrid_speed_tuning.json)，不混入当前18项结果。

## 当前物理边界

PMSM使用合成的磁饱和Jacobian和正常J/B，未将书中样机曲线当作本电机标定。逆变器为平均模型；作用电压在MIL中理想已知，实际PWM器件、采样窗口、模拟前端和电压重建误差尚需相应硬件/开关模型。0 V退出仍可能产生制动电流及外部负载带动的转动，不表示高阻关断。

低速约.0195 rad偏差包含HFI解调/滤波/处理滞后。普通/Accelerator逐点一致属于同一MIL模型的执行核对，不能记为SIL、C2000耗时或实机性能。后续仍按专项计划完成其他观测器、无感MTPA/弱磁、single/SIL和两个C2000目标。
