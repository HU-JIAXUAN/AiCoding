## 正常启动及π分支

22项物理MIL在隔离副本通过，受测SLX、M源和结果按SHA256核对输出；正式路径默认6份日志与受测默认工况逐列核对。最终搭建脚本另在无App SLX的目录重建并运行，6份默认日志也完全一致。库原24项轴线工况前37列仍与旧结果完全一致，新接口另扩展6项轴线检查。探针内部System XML和算法源码未改变，并复跑旧名义工况及默认路径检查；原27项证据继续保留。

默认初始电角.7 rad，探针得到平均逆电感约834.351 1/H，HFIAxis使用该值而非名义833.333 1/H。轴线锁定、停HFI和电流衰减后执行双脉冲，正侧基线修正峰值3.75863 A、负侧2.74799 A，差1.01063 A；两侧实际剂量均.004 V·s。约86.45 ms恢复轴线锁定并输出完整位置资格。

初始电角增加π时，轴线仍等价，正、负侧峰值约2.74160/3.76915 A，差−1.02756 A；flip_pi=1，约86.90 ms获得完整位置。默认/反向工况末段误差接近数值精度，只说明理想同参数模型自洽，不作为实际测量精度。见[启动顺序](startup_sequence.svg)、[π及ADC](startup_polarity.svg)。

峰值按各侧静息基线修正，不能直接拿电流绝对最大值代替。实际电压积分按u[k−1]与i[k]配对；一拍执行延迟或电流/电压一起晚一拍时，两侧仍各.004 V·s并正确识别。实际电压减半时各.002 V·s，峰值差约.38063 A，仍满足当前门限。

## 测量、参数及复位

三相ADC使用±8 A范围、12位步距16/4096 A、每相1 mA RMS独立噪声、种子42。完整角RMS约.00562469 rad，末段有效比例1；这些是测试参数，未标定P650实际模拟前端。名义Ld/Lq改为2/3 mH时，本App仍用探针实测均值，默认响应不变。

已验证探针运行期间禁能/复位，以及完整跟踪后禁能/复位，均清除旧极性并重新检测。探针结果经一拍快照交接；停止执行后的第一拍仍可能收到上一拍运行期间产生的复位结果，之后保持不变。测试按该明确时序检查，不要求无延迟快照。

全局enable/reset还门控平均电压请求，避免探针快照延迟使禁能时残留请求。可选执行延迟代表真实施加电压的流水线，不能据此宣称物理逆变器已立即高阻关断。

## 应拒绝的工况与限制

| 工况 | 实测结果 | 判定 |
|---|---|---|
| 凸极存在、无磁极饱和非对称 | 峰值差−.005259 A，实际剂量仍各.004 V·s | fault5，对比不足，known=0/valid=0 |
| 圆转子Ld=Lq | 探针quality4，qualified=0 | 不启动HFI/极性，最终电压请求为0 |
| 负脉冲实际电压仅70% | 峰值差反而增大至1.80168 A；剂量.004/.0028 V·s | fault4，不将执行差误当极性 |
| 电流晚一拍、电压未对齐 | 逆电感均值约−496.96 1/H、quality3 | 探针拒绝，后续不启动 |
| 外部恒转矩维持约5电角rad/s运动 | 等轴线阶段无法满足2 rad/s速度准入 | fault2，无极性结论；不是带速启动已完成 |
| 正脉冲a相ADC故障偏置 | 测得电流模超过6 A | fault1，启动退出，known=0 |
| 已识别后撤销凸极资格 | 状态8/fault6，valid=0 | 保留诊断极性锁存，停止请求，需禁能/复位重启 |
| 未知交叉增量电感.2 mH | valid仍为1，角RMS约.337210 rad | 保留模型先验不足的反例，不认作可靠角度 |
| 已知同一交叉电感并补偿 | 角RMS约.00256270 rad，valid=1 | 当前合成饱和模型下可用，仍需实际电机标定 |

阶段、脉冲和实际剂量的图见[拒绝工况](startup_rejection.svg)。平均逆电感校准和独立凸极资格不能消除未知交叉电感方向偏置；本实现仍依赖方向先验、饱和符号及适用电机条件。
