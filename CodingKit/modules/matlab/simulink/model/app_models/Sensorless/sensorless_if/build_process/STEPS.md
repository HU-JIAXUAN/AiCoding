# I-f App 搭建

1. **先接公用启动命令。** 从工况源拆出五列，将对象电流和端电压幅值以控制周期采样，送入 [OpenLoopDrive](../../../../lib/无感启动/README.md)。观察通过后，零频率对齐，随后斜坡运行。门极许可决定桥模式。
2. **组装控制和电机。** 由软件角做 Park，给定 [幅值,0]，TrackingPI 得到虚拟 dq 电压；最终限幅与原请求之差回馈积分。将限幅后的电压做逆 Park 和 SVPWM，用实际母线驱动桥与 SPMSM。实际速度和角度只引到诊断分支。
3. **分开速率与记录。** 对象 12.5 μs，控制 62.5 μs；电流、保护幅值和端电压幅值各经采样保持。I-f PI 比例和积分都按控制周期更新。工况源按行从离散表读取；保留采样时间数组仅用于输出对齐。Scope 手动打开，快/慢两种记录分开。
4. **跑正常和失步反例。** 检查正反转、初角、低压、限频、负载、保护及带速重启拒绝。故障未置位的失步也保留，避免把“没有报警”当作已同步。

搭建时使用库链接和模型编辑接口，并用原生编译核对接线及周期。禁能/复位使用桥模式 0，运行使用模式 1；模式 2 是主动短接，不用于本 App。
