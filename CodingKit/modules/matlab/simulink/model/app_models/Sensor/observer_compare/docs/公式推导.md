# 位置反馈控制下的观测器并行对照

## 1. 控制与观测分支的作用

SensorObserverCompare保留MotorExperiment的Sensor反馈闭环，只增加没有Outport的ObserverMonitor。因此估角不反馈到Park、电流环或速度环；可以比较同一实际运行下的观测误差。原有52列trace保留，另加28列observer_trace。

## 2. 电压、电流和参考必须具有同一年龄

最终实际相电压包含执行延迟及启用时的物理死区误差。其Clarke输出先采样，再延迟FeedbackTicks拍；电流和位置参考来自相同反馈帧。若共同延迟为$N_f$，监测分支使用

$$
\boldsymbol i_o[k]=\boldsymbol i_{sample}[k-N_f],\quad
\boldsymbol u_o[k]=\boldsymbol u_{sample}[k-N_f],\quad
\theta_{r,ref}[k]=\theta_{r,sample}[k-N_f].
$$

基础SMO用$i_o[k]$校验同拍估计，$u_o[k]$用于下一状态预测。当前Plant角仅用于检查样本年龄；若直接与当前角比较，会额外引入约$\omega_rN_fT_s$的假误差。

## 3. 误差公式与在线资格的分工

离线评价使用

$$
e_\theta=\operatorname{atan2}(\sin(\hat\theta_r-\theta_{r,ref}),\cos(\hat\theta_r-\theta_{r,ref})),\quad
e_\omega=\hat\omega_r-\omega_{r,ref}.
$$

时间窗$\mathcal W$内$\mathrm{RMS}(e)=\sqrt{\sum_{k\in\mathcal W}e[k]^2/|\mathcal W|}$，峰值为该窗最大绝对值。方向保留符号，不能比较绝对速度后忽略反转分支。

SMO在线只消费实际电压、采样电流、显式方向先验、enable/reset。真实角误差不参与valid判定。算法推导见[基础SMO](../../../../lib/观测器/滑模/docs/公式推导.md)，单L模型限定SPMSM。

## 4. 参数失配如何构造

对象与观测器的$R_s,\ell_{sp}$分别来自各自配置。只修改smoCfg.Rs并刷新离散系数可得到电阻估计误差；两边一起改并不构成同一意义的失配实验。反馈年龄、控制周期、PWM周期和Plant步长改变时需同步对应配置。

## 5. 实现与运行

`src/SensorObserverCompare.slx/ObserverMonitor`维护新增监测连接，底层估计链接SlidingModeObserver，原控制链不增加算法副本。[observer_compare_parameters.m](../parameter/observer_compare_parameters.m)为本地配置入口；[参数/6组监测Scope](../parameter/README.md)、[搭建与运行](../build_process/USAGE.md)、[结果](../waveform_analysis/README.md)记录实际输入和时间窗。本App通过不表示估计闭环已接管，闭环接管由Sensorless App另验。

书中物理量与工程标识/单位见[本模块参数映射](../parameter/README.md#原书符号与工程标识)。控制器局部状态、矩阵和设计量按正文定义，不覆盖用户符号表。
