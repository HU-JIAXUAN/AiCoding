# 单关节闭环验证

| 字段 | 记录 |
|---|---|
| 模型文件 | [src/MitJointControl.slx](../src/MitJointControl.slx) |
| 参数文件 | [parameter/mit_joint_parameters.m](../parameter/mit_joint_parameters.m) |
| 采样周期 | MIT、FOC 和记录 100 µs，常规外环 1 ms |
| 求解器/步长 | `ode4` 固定步长 5 µs |
| 工况 | 五参数公式、纯转矩、刚度与阻尼、限流、过压、复位和原控制支路一致性 |
| 数据文件 | 仿真输出 `mitTrace`、`trace`，验证函数返回指标结构体 |

在 MATLAB 中将本目录加入路径并执行 `run_mit_joint_validation`。各工况通过 `SimulationInput` 覆盖配置。

## MATLAB R2026b Update 1 验证结果

| 工况 | 结果 |
|---|---|
| 五参数和前馈 | 五参数转矩公式、前馈离散递推及选中 dq 电流指令逐采样核对通过 |
| 纯转矩 | 给定 0.3 N·m 时，稳态平均 q 轴反馈电流为 0.22968 A，参考为 0.23810 A |
| 关节刚度 | 0.18 N·m 载荷下，$K_p$ 为 2 和 4 N·m/rad 时，稳态位置偏差分别为 0.09047 和 0.04541 rad |
| 关节阻尼 | $K_d$ 从 0.025 增至 0.12 N·m·s/rad 后，0.75–1.30 s 内最大位置误差从 0.10051 降到 0.02020 rad |
| 限流、母线过压、复位 | 正负限流、过压下 q 轴电流指令置零、复位下前馈和电流指令置零均通过 |
| 原位置／速度支路 | 与 `MotorExperiment` 使用相同工况，速度模式与位置模式的全部 `trace` 通道最大绝对差均为 0 |
| 独立进程加载 | 从绝对路径直接加载模型并运行 0.12 s，输出 1201 个有限样本 |
