# Clarke 变换

[ClarkeTransforms.slx](ClarkeTransforms.slx) 提供 `Clarke`（abc → αβ0）和 `InverseClarke`（αβ0 → abc）。两块采用幅值不变约定并保留零序。

受保护发布文件：[Clarke](ClarkePark_ClarkeProtected.slxp)、[InverseClarke](ClarkePark_InverseClarkeProtected.slxp)。使用 [ClarkeParkTest](../ClarkeParkTest.slx) 检查正、反变换及往返误差。
