# Park 变换

[ParkTransforms.slx](ParkTransforms.slx) 提供 `Park`（αβ → dq）和 `InversePark`（dq → αβ）。电角度采用 rad，零角度时 d 轴沿 α 轴。

受保护发布文件：[Park](ClarkePark_ParkProtected.slxp)、[InversePark](ClarkePark_InverseParkProtected.slxp)。使用 [ClarkeParkTest](../ClarkeParkTest.slx) 检查正、反变换及往返误差。
