# 按两路位置估计搭建双向融合

理论起点是主参考书5.9节、印刷144–145页/PDF173–174页，图5.49(a)、5.50及式(5.67)–(5.68)。采用两套独立跟踪器的位置融合；误差信号融合不在本实现中。书中样机的转速、注入幅频不直接作为本工程参数。原单向I-f接管块继续保留，不用它替代双向融合。

模型由[build_hybrid_fusion.m](build_hybrid_fusion.m)向原SensorlessHandover库追加HybridFusion，另建独立测试台。原Handover接口、源码和计算不改。搭建脚本拒绝覆盖已存在的新块/测试台，重建在隔离副本进行。

从当前已完成目录重新搭建时：先关闭当前模型并复制整个模块到临时目录；打开副本的SensorlessHandover库，解锁后仅删除HybridFusion，保留原Handover，保存并关闭；将副本的HybridFusionTest.slx移到副本外保留，再将副本的src、parameter、build_process加入MATLAB路径并运行build_hybrid_fusion。这样可直接从现有交付物重建，正式目录保留不动。脚本会检查载入库与脚本所属模块路径一致。

1. 明确两路输入：低速完整位置/估速/资格、基波完整位置/估速/资格，再加使能和复位。真实位置、真实速度均没有库输入端口。
2. 在各自预测相位周围检查本路创新，并检查适用速度、有限值；首次资格要求连续累计。两路接近时再检查包角差与速度差，避免把错误方向或大相位差直接混入控制。
3. 启动时可用已识别极性的低速位置取得控制资格；配置允许时也可用合格基波位置带速取得资格。后者在本测试台只验证逻辑，真实带速捕获另由App验证。
4. 用速度幅值生成基波权重，对权重限变化率。角度先求包角差再加权，避免±π附近直接算术平均。带符号速度保留用于旋转和方向。
5. 将候选融合角与上一融合角按基准速度推进的预测比较，对附加相位修正率限幅。输出物理基准估速和坐标变化率两个量，便于App分别处理速度环、前馈和PI坐标状态。
6. 基波已完全接管且达到撤除速度时，将注入目标改为0并按斜率下降。降速到恢复边界或基波失效时，目标改为1。单独保存目标，形成真正的迟滞。
7. 注入停止后清除旧低速分支信任。恢复时仅在基波仍合格且完全接管的区间比较低速候选及其加π候选，选择与基波一致的一支；再连续确认低速资格，才允许权重返回低速。基波已丢失而低速分支未知时，不猜测磁极方向。
8. 短时没有合格来源时按上一安全速度预测，超过LossTime锁存退出。单路失效且另一条已合格时选用可用来源，最终相位仍按修正率过渡。reset/disable清全部状态。

全部20状态放在可见UnitDelay；[hybrid_fusion_step.m](../src/hybrid_fusion_step.m)只计算下一状态和诊断，无persistent。注入输出由独立的[hybrid_injection_output.m](../src/hybrid_injection_output.m)读取保持状态和使能/复位，避免“本拍注入→本拍HFI资格→本拍注入”的代数环。普通来源失效故障的注入归零有最多一拍状态延迟，最终整机门控另行处理。

本工程在书中位置融合关系上增加资格、π分支重接、迟滞、速率限制和故障处理。它们是为组合实际离散模型补充的实现，不标成书中逐块原样框图。端口、状态、参数和Scope逐项见[参数页](../parameter/FUSION_PARAMETERS.md)，运行见[操作方法](FUSION_USAGE.md)。
