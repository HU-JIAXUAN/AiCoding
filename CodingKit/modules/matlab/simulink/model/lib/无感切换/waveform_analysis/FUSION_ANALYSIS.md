## 验证检查什么

[验证脚本](run_hybrid_fusion_validation.m)在R2026b隔离副本完成30项，全部通过，逐项结果见[指标](fusion_metrics.json)。受测模型和数据按SHA256更新到正式路径；从原库重新搭建的默认27列输出一致，原单向接管19项逐条回放也与旧记录一致，详见[核对记录](fusion_verification.json)。

默认首次valid为9.95 ms，有效期间角RMS约.023751 rad；该值来自夹具设定的两路−.03/+.02 rad偏差，不能解释为实际电机估算精度。注入达到0后恢复到1，最终低速额外π分支为1、基波权重回到0。图见[往返与分支](fusion_round_trip.svg)、[故障过程](fusion_faults.svg)。每项保留输入、参数、时间、27列trace及离线角误差，不把正确拒绝/故障工况当作可运行速度点。

| 工况组 | 可检查行为 |
|---|---|
| 正/负往返、包角、换向、同分支/反π返回 | 完成低→高→低，注入撤除和恢复，π分支确认；融合角误差和本拍变化率受约束 |
| 单低速、正/负基波带速、禁用带速、没有来源、超出低速范围 | 只接受已满足条件的来源；不满足时保持等待，不伪造初始极性 |
| 两路相位/速度不一致、首次资格中断 | 拒绝不一致来源；中断后首次连续资格重新计时 |
| 低速/基波短缺样、基波短NaN | 在2 ms预算内有界预测并恢复；非有限输入不传播到输出 |
| 低速/基波持续缺样、基波持续相位突跳 | 在规定窗口到达故障1，valid退出且故障锁存 |
| 已使用基波时低速NaN、任一路失效而另一路已合格 | 不消费无效来源；选可用来源并限制最终相位修正 |
| 禁能重启、显式复位、故障后复位、非法命令 | 清状态、重新资格；非有限使能/复位为故障2 |
| 高速失去基波且低速分支未知 | 不用未经锚定的低速角强行接管，预测超时退出 |
| 注入迟滞、1 ms周期 | 撤除/恢复速率按物理时间保持，迟滞区不抖动 |

通用检查包括所有输出有限、角度包角范围、权重/比例边界、禁能/复位清零、故障时valid=0、注入正常变化率、相位附加修正率，以及连续有效样本的`omega_frame=wrap(theta[k]−theta[k−1])/Ts`。正常双路合格时检查beta的变化率；故障回退可直接选择另一已合格来源，最终控制角仍限相位修正率。

低速候选的π跳变是刻意的重接反例。通过相位与速度一致性选择分支只利用基波估计，不使用测试真实角度；它不等价于磁饱和极性识别。若两路共享偏差，融合资格无法证明真实角精度，因此不能把本台解析角误差当作整机性能。

## 与整机验证的关系

本测试只证明融合调度和故障行为。下一步在现有HFI物理App并行接入IPMSM适用的基波估计，实际注入作用于电机，实际采样电流返回两路观测器；再检查低→高、高→低、反转穿零及电流/转矩/执行电压、PI坐标状态。原HFI低速FOC24项不替代这些新的物理融合工况。single/SIL、C2000构建与实机耗时也另行验证。
