# 采样保持、反馈延迟与执行延迟

## 1. 连续对象与离散控制器的连接

电流和反馈角度必须属于同一物理采样时刻。周期$T_s$的零阶保持把连续输入变成

$$
x_s[k]=x(kT_s),\qquad x_h(t)=x_s[k],\quad kT_s\le t<(k+1)T_s.
$$

Feedback和Actuation均先做ZeroOrderHold，再选取无附加延迟的保持值或整数拍延迟值。关闭UseTiming并不取消采样保持。

## 2. 整数拍延迟及初值

配置$N_f,N_a$分别为反馈、执行拍数：

$$
y_f[k]=x_s[k-N_f],\qquad y_a[k]=u_s[k-N_a],\qquad
G_f(z)=z^{-N_f},\quad G_a(z)=z^{-N_a}.
$$

Delay块初值为0；尚未填满的历史样本取0。UseTiming为0时选择$x_s[k]$或$u_s[k]$。$N=0$没有附加整数拍延迟，仍有离散采样本身。

延迟在角频率$\omega$带来$-\omega NT_s$相位。因此提高PI带宽时不能只看RL对象。默认$T_s=100\,\mu s$，每拍附加延迟就是$100\,\mu s$。

## 3. 共同反馈帧与多速率

整机共同帧按$[i_a,i_b,i_c,\theta_r,\omega_m,\vartheta_{shaft},\omega_r]$采样和延迟，再做Clarke/Park。真实角度与电流若分属不同时刻，即使两者各自正确，也会引入dq误差。

当前整机示例外环1ms、电流100μs、对象5μs；初始化检查外环周期是电流周期整数倍，电流周期可被对象步长整除，timingCfg.Ts等于currentCfg.Ts。数学上要求

$$
T_{outer}=nT_s,\quad T_s=mh_{plant},\quad n,m\in\mathbb N^+.
$$

## 4. 模型对应与边界

`ControlTiming.slx`的Feedback、Actuation分别为ZOH→Delay→选择器。`TimingTest.slx`逐点核对阶跃延迟0/0、1/1、2/3拍。时间单位s；通道顺序、原始/保持/延迟变量见[参数页](../parameter/README.md)。

[参数入口](../parameter/timing_parameters.m)、[搭建记录](../build_process/STEPS.md)、[运行方法](../build_process/USAGE.md)。该模型未描述ADC量化、窗口、真实PWM相位、ISR或非整数延迟；整数拍仿真不能证明C2000截止时间。

书中物理量与工程标识/单位见[本模块参数映射](../parameter/README.md#原书符号与工程标识)。控制器局部状态、矩阵和设计量按正文定义，不覆盖用户符号表。
