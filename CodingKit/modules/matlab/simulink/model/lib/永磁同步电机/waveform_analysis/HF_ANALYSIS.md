# 高频/饱和PMSM对象验证

| 字段 | 值 |
|---|---|
| 模型文件 | src/PMSMHighFrequencyPlant.slx；src/PMSMHighFrequencyPlantTest.slx |
| 参数文件 | parameter/pmsm_hf_parameters.m；parameter/hf_plant_test_parameters.m |
| 采样周期 | 电压与输出50 μs；连续物理状态由求解器积分 |
| 求解器/步长 | ode4，固定2.5 μs |
| 工况 | 14项物理对象MIL；另有51个电流工作点的磁链Jacobian/电压平衡检查 |
| 数据文件 | waveform_analysis/hf_results.mat；waveform_analysis/hf_metrics.json；waveform_analysis/hf_verification.json |

R2026b中隔离候选14项检查通过后，模型、数据和波形按SHA256迁入正式目录。正式路径已核对内嵌Dynamics与src/pmsm_hf_dynamics.m一致，并重新运行默认工况及全部14项。每项保存实际电机参数、工况、输入、13列trace和指标。

## 检查内容与结果

| 工况 | 结果 |
|---|---|
| d轴/q轴线性RL | 与独立矩阵指数零阶保持解比较，最大误差分别5.82e-14 A、7.55e-15 A |
| 旋转坐标与交叉电感 | 独立线性解误差分别3.46e-14 A、1.48e-14 A；核对坐标及2×2电感耦合 |
| 正向饱和脉冲 | +4 V峰值3.76187 A，−4 V峰值绝对值2.73658 A，差1.02529 A |
| 电压轴反向π | 峰值差变为−1.02529 A，验证极性比较的符号关系 |
| 关闭饱和 | 正负峰值均约3.14775 A，差5.33e-10 A；常参数磁路不给出本例所需的极性差异 |
| 理想锁轴、偏轴π/4脉冲 | 有电磁转矩，但速度和位置保持不变；夹具约束与自由运动分开 |
| 自由转动、偏轴π/4脉冲 | 最大电角速度6.40242 rad/s，最大电角位移0.07937 rad；约为机械0.01984 rad |
| 正负载、零外加电压 | 转子沿负方向运动并产生电流，最大电角位移约0.32091 rad |
| 无凸极、两个初始角 | 相同αβ电压产生相同αβ电流，差小于1e-10 A，体现该条件下的角度不可辨识性 |
| 有凸极高频方波 | 5 V、10 kHz的α轴方波在偏转子轴工况下产生可观测β电流，RMS大于0.01 A |
| 无凸极高频方波 | 相同激励的β电流小于1e-10 A；两种方波工况也分别通过线性精确解检查 |

共有9个线性锁轴工况使用解析对照；非线性/自由转动工况未套用线性解析解。hf_metrics.json以linear_reference_checked明确区分，未使用时误差字段为null，而不是0。

51个不同id工作点的数值磁链Jacobian与增量电感矩阵最大差约3.15e-13 H；电压平衡最大残差约1.83e-15 V。参数入口保证全电流范围的增量电感正定。以上数值是合成数学对象的一致性证据，不是实际电机参数精度。

## 波形如何看

| 图 | 观察重点 |
|---|---|
| [正向饱和](hf_positive_saturation.png) | 正负电流幅值及Ld增量变化，位置/速度保持零 |
| [反向电压轴](hf_reversed_axis.png) | 峰值大小关系反转 |
| [自由转动](hf_free_rotor.png) | 偏轴电流产生iq和转矩，转子实际移动；不能把锁轴测试当作无位移证据 |
| [凸极方波](hf_hf_square_salient.png) | αβ高频电流与几何凸极的关系；可在原始数据中缩放到几个采样周期查看 |

每张图有同名SVG，原始数据包含整个0–0.1 s。Scope通道、单位及trace列号见[HF_PARAMETERS.md](../parameter/HF_PARAMETERS.md)。

本阶段验证物理对象，尚未在该测试台内搭建HFI解调器、PLL、极性状态机或无位置转矩闭环。下一阶段需要在此对象上验证轴线捕获后再施加极性脉冲，并记录峰值差、判定资格及实际位移；模型本身的极性响应不等于观测器已经识别成功。
