# 正交探针的搭建与作用

单方向HFI依赖名义平均逆电感，圆转子在平均模型设错时也可能通过幅值/PLL门限。为在完整启动前检查实际凸极性，本模块增加独立SaliencyProbe，输出测得的张量、特征值、轴线快照和平均逆电感。

理论基础是主要参考书第4.2节、印刷79–82/PDF108–111页的磁链Jacobian和增量电感；本工程采用的短时正交激励、二阶差分回归及资格门限自行设计，不声称书中已有同名完整框图。双脉冲极性对应第8.2节，现已在同库独立实现，见[极性搭建](POLARITY_BUILD.md)。

## 1. 分开状态更新和请求输出

`ProbeStates`是19元素、50 μs的UnitDelay。`Update`接收状态、实际电流、实际电压、active和设置，只产生下一状态；`Output`仅接状态、active和设置，产生16元素输出，随后Demux连接端口。这样实际u[k]只写入历史，不直接影响同拍的注入请求，避免人工代数环。

active为enable&&!reset。参数用局部Mask的cfg结构体传入，调用处填写本模块M文件生成的probeCfg。构建时先用参数函数建立局部作用域，再设cfg.Ts；不读取或清除base workspace的同名cfg。

## 2. 从实际响应求二维矩阵

请求按`+axis,−axis,+orthogonal,−orthogonal`循环，默认ProbeAxis=0，因此对应+α、−α、+β、−β。每段50 μs、5 V；32拍预热后累积256拍，默认14.4 ms结束。测试台的实际执行增益和延迟放在请求之后，送回探针的是实际电压。

约定i[k]结束u[k−1]区间，每次累积：

```text
x = u[k−1] − u[k−2]                 [V]
y = (i[k] − 2*i[k−1] + i[k−2])/Ts   [A/s]
XX += x*x';  YX += y*x';  YY += y'*y
Araw = YX/XX                         [1/H]
A = (Araw+Araw')/2
```

矩阵只有2×2，生产函数使用显式行列式运算，不调用通用矩阵逆/特征值求解器。正交激励提供两个独立方向；XX秩不足时直接拒绝资格。常量电流偏置由差分抵消，有限Rs、转动、量化和噪声仍会带来误差。

## 3. 资格与轴线分别解释

对称矩阵的特征值差给出凸极比；同时检查实际电压激励、正定范围、原始拟合残差和反对称度。名义Ld/Lq不参与张量回归。轴线方向来自`.5atan2(2Aab,Aaa−Abb)`，已知CrossPhase时再修正一半；未知交叉电感的轴偏差仍须保留。

done表示采集结束，qualified才表示该快照通过门限。圆转子也会有数值方向输出，但qualified应为0，不能使用该方向。所有轴线仍有π歧义，不输出完整位置或极性资格。

## 4. 复位、停止和快照时间

禁能/复位时请求立即为0，更新状态清零。电流超限或输入非有限值记录故障，下一拍停止请求。正常完成后停止激励并保持张量，后续电流变化不改变旧快照；它不承担整机持续保护。

张量来自整个采集窗口，输出是窗口轴线快照。移动转子在done时刻已经继续运动，不能把该值当成同拍连续位置。独立测试保留移动轴工况并记录这个误差；后续仍由连续HFI跟踪，再判断双脉冲适用条件。

## 5. 测试装配和复现

测试台引用共用PMSMHighFrequencyPlant、InverseClarke和Clarke；三相ADC复用本模块hfi_measure_current。真实角度只进入误差和Scope。锁轴是显式夹具工况；默认自由机械沿用原J/B，没有人为增大惯量或阻尼。

[build_hfi_probe.m](build_hfi_probe.m)通过model_edit向既有HighFrequencyObserver库追加SaliencyProbe并创建HFISaliencyTest；它拒绝覆盖已有探针/测试台，应在隔离副本运行。既有HFIAxis的算法、参数与接口保持原样。
