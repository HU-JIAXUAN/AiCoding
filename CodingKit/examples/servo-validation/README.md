# 伺服算法纵向宿主验证

将参数辨识、控制器、前馈、逆变器补偿和最终约束串成三条可运行的 C99 案例。
所有电流、位置和端电压均来自本例生成的合成数据；没有连接真实驱动器、电机或 MATLAB。
通过表示本例模型与验收工况下的宿主行为成立，不表示板上时序、参数、机械性能或量产已通过。

## 运行

从任意目录执行，输出目录必须位于本例源码目录之外：

```powershell
python -B CodingKit/examples/servo-validation/run_validation.py --cc C:/msys64/ucrt64/bin/gcc.exe --output <工作目录>/cases-build
```

也可省略 `--cc`，从 PATH 查找 GCC。脚本只编译本例与共享源码，不修改固件构建、公共 CLI、
测试注册表、Hook、PID/FOC/IF 或插件依赖。它分别使用 `-O0` 与 `-O2`，两者均启用
`-std=c99 -Wall -Wextra -Werror -pedantic`；任一编译、执行、输入契约或数值验收失败均返回非零。

汇总同时检查二进制退出码、数值断言和A/B参考一致性。即使二进制先输出通过JSON、随后退出非零，最终结果仍失败。汇总器回归可独立运行：

```powershell
python -B CodingKit/examples/servo-validation/test_runner.py --work-dir <工作目录>/runner-tests
```

输出包括 `results_debug.json`、`results_release.json`、`summary.json`、两个 `trace_*.csv`、
编译与执行日志、两个宿主可执行文件。报告记录实际编译源码的 SHA-256；CSV 不含墙钟时间。
本例新增 C 使用 CP936、LF、无 BOM；Python/Markdown 为 UTF-8，共享源码保持各自实际编码。
源码目录内不生成 build、exe、缓存或报告。

## 复用和组合边界

- [轻量 PI](../../modules/common/controller/pid/src/pid_pi.h)：先评价、后跟踪，一拍只提交一次。
- [坐标变换](../../modules/common/controller/foc/src/foc_math.h)与
  [SVPWM](../../modules/common/controller/foc/src/foc_svpwm.h)：唯一共享源码，没有复制实现。
- 本例不经过旧 `Foc` 包装；直接在示例层组织前馈、最终调制和回算，保持原入口行为。

`DriveInput` 是一拍的三相电流 A、母线 V、角度 rad、电角速度 rad/s 及 dq 电流请求 A。
`drive_update()` 返回下一拍门极电压、补偿、约束残差、积分及有效性；非法输入不改变实例和输出。
`Trajectory` 只产生运动参考；电机参数估计、轨迹、控制器和独立真值对象各自拥有状态。
这些 `static` 函数是有明确范围的宿主演示，尚未作为通用算法模块 API 发布。

## 独立对象与离散时序

电气/机械真值使用双精度 PMSM dq 方程、磁阻转矩项、惯量、黏性阻力与外部负载，
每个 50 µs 周期用四个子步 RK4 积分。控制器使用共享 `float` 原语。
真值对象从独立三相定义生成电流；对象导数没有调用控制器的解耦或补偿函数。
电流、角度和速度在周期起点采样；新门极指令延迟一个周期才作用于对象，周期内保持。
母线突变时保持的是上一拍 duty，相应电压随新母线缩放。

基础真值为 `Rs=0.55 Ω`、`Ld=1.5 mH`、`Lq=2.3 mH`、永磁磁链 `0.02 Wb`、极对数 4。
运动案例采用 `Ld=Lq=1.5 mH`，`J=0.002 kg·m²`、`B=0.001 N·m·s/rad`、
额外常负载 `0.02 N·m` 与 `0.035*sin(position)` N·m 重力项。
静态负载没有提供给前馈，仍需反馈控制消除误差。

## 案例 1：参数辨识 → 离散 PI → dq 解耦

三组 RL 真值：`R=0.4/0.55/0.7 Ω`，`Ld=1.2/1.5/1.8 mH`，`Lq=2.0/2.3/2.6 mH`。
每轴训练 4,000 拍，用精确 ZOH 递推生成电流和峰值 0.2 mA 的确定性测量噪声，
通过二参数最小二乘求离散极点和输入增益，再换算 R/L。训练初值为 -1.7 A。
留出段改变激励频率、幅值及初值为 2.3 A，预测器自由递推 2,000 拍，不逐拍用真值电流重置。
零激励、非法周期和无法得到正物理参数的求解拒绝发布结果。

中间一组辨识结果用于 PI 和解耦，PMSM 对象仍保留独立真值。磁链和极对数在此例中已知，
未声称已辨识磁链、惯量或完成通用自动整定。PI 采用连续模型起点 `Kp=L*1000`、`Ki=R*1000`，
以真实离散闭环验证该起点；不是仅检查两条增益公式。
两次 A/B 的 PI 增益、初值 `Id=0.7 A/Iq=-0.5 A`、48 V 母线、600 rad/s 电角速度及
`Iq: 0 → 3 → -2 A` 相同，只切换 dq 补偿。

| 指标 | 通过阈值 |
|---|---|
| 三组最大 R、L 相对误差 | 分别 ≤2% |
| 留出自由递推电流 RMSE | ≤0.01 A |
| 解耦后 d 轴 RMS | ≤0.08 A，且 ≤未解耦的50% |
| 末尾 20 ms 的最大 q 轴误差 | ≤0.02 A |

d 轴 RMS 统计两个阶跃后 `[40,90)` ms 与 `[120,170)` ms，不含初始收敛段。

## 案例 2：jerk 受限参考 → 前馈 → 三环跟踪

轨迹起点匹配当前命令的 p/v/a，终点为目标位置及零速度、零加速度。
先搜索五次 Bezier 位置段，用导数控制点的凸包界检查全程速度、加速度及 jerk 上限。
直接段不可行时，先用常 jerk 将当前加速度回零，再用三段 jerk 制动至静止，最后接五次段。
若该制动会越过速度限值，或有界搜索未找到段，返回失败并保留旧段。

该方法覆盖本例非零初态重规划，允许必要的位置超调，没有工作空间和障碍物约束。
它不是任意初态的通用时间最优规划器，也不是静止到静止固定七段 S 曲线的替代定义。
p/v/a 连续，jerk 允许有界分段跳变。除解析边界比较，还以相邻样本差分核对位置/速度导数。

测试在 0、0.35、2.2、3.0 s 请求 `0.8/-0.25/-0.24/0.55 rad`，包含加速中反向改目标及
0.01 rad 短行程。上限为 `2.5 rad/s`、`10 rad/s²`、`100 rad/s³`。
位置/速度环更新率 1 kHz，电流环 20 kHz；位置 P 为 20 s⁻¹，速度 PI 为
`Kp=3 A/(rad/s)`、`Ki=166.6667 A/rad`，电流 PI 连续设计带宽为 1200 rad/s。

前馈开启时，位置环叠加解析参考速度，速度环电流请求叠加
`(J*a_ref+B*v_ref+gravity(position_ref))/Kt`；本例 SPMSM 的 `Kt=0.12 N·m/A`。
不同电机类型不能直接沿用固定 Kt，需使用对应转矩模型或映射。

A/B 使用相同轨迹、增益、初始状态、母线及负载，只切换这两项前馈。
Python 还逐行核对两次 CSV 的 6,000 组时间及 p/v/a 参考完全一致。

| 指标 | 通过阈值 |
|---|---|
| 全程参考 v/a/j | 各自不超过上述限值 |
| 重规划 p/v/a 边界差 | ≤1e-10（按各自单位比较） |
| 位置差分与平均速度之差 | ≤1e-5 rad/s |
| 速度差分与平均加速度之差 | ≤0.003 rad/s² |
| 前馈位置 RMSE | ≤0.002 rad，且 ≤关闭前馈的50% |
| 前馈位置峰值误差 | ≤0.006 rad |
| 两次峰值电流 | 各自 ≤6.2 A |
| 末段参考完成后的稳定时间 | 各自 ≤0.5 s |
| 最终位置误差 | ≤0.001 rad |

位置 RMSE、峰值误差和电流峰值在全部 6 s、120,000 个控制采样上计算。
稳定时间从最后一段参考实际完成时刻起计，取此后最后一次离开
`|p-0.55|≤0.001 rad` 且 `|v|≤0.01 rad/s` 窗口的时间；若完成时已稳定则为零。
脚本记录 A/B 各自数值，不要求加入前馈必然降低峰值电流。

## 案例 3：死区补偿 → 最终电压可实现性 → anti-windup

逆变器真值逐相损失为 `Vbus*0.025*(2/pi)*atan(i/0.025 A)`，
补偿估计为 `Vbus*0.025*i/sqrt(i²+(0.045 A)²)`；两者形状不同。
这是可复现的非线性误差模型，不含开关器件、二极管换流、测量滤波或实际温度特性。
补偿平滑尺度是该合成对象的设计值，移植时须重新标定。

补偿与 dq 前馈相加后，以 `0.94*Vbus/sqrt(3)` 限制电压矢量，调用真实共享 SVPWM，
再从最终 duty 重构电压。duty 必须保持在 `[0.03,0.97]` 内。
这里只将“重构门极电压 − 全部门极请求”映射回 dq，加到原 PI 候选以调用 `pid_pi_track()`。
补偿本身没有被误计为饱和，也没有把门极电压当作电机端有效电压。

补偿 A/B 使用同一 400 rad/s 电角速度及 `Iq: +0.35/-0.35/+0.10/-0.10 A`，
分别保持 0.2 s，检验力矩/电流翻转和小电流。AW A/B 使用同一 80 rad/s 电角速度、
`Iq=12 A`，80–300 ms 母线从24 V降至6 V，300 ms 恢复24 V且请求归零。

| 指标 | 通过阈值 |
|---|---|
| 无饱和时重构约束残差与补偿导致的额外积分变化 | 各自 ≤1e-5 V |
| ±0.02 A 过零扫描，步长0.1 mA | 补偿单调、零电流补偿为0、相邻差≤0.0021 V |
| 补偿后电流 RMSE | ≤0.08 A，且 ≤未补偿的50% |
| duty 越界 | ≤2e-6（浮点容差） |
| 降压工况饱和拍数 | ≥1,000拍，确认实际触发约束 |
| AW 恢复时间 | ≤0.12 s，且 ≤无AW的70% |
| 最终电流矢量幅值 | ≤0.05 A |

电流 RMSE 是 dq 跟踪误差矢量的 RMS，只统计每次换向60 ms后的稳态段。
恢复时间从300 ms起，取最后一次电流矢量幅值超过0.05 A后的一个采样周期，
后续必须一直保持在窗口内。无AW基线同样记录恢复时间，且要求在0.5 s内恢复。

## CSV 与证据解释

`gate_request_*` 是本拍未限幅门极电压请求，`gate_next_*` 是最终 duty 重构的下一拍门极电压；
`effective_held_*` 是本周期实际保持、已扣除真值逆变器损失的合成端电压。
电流、角度、位置和速度来自周期起点；积分列是本拍候选成功提交后的状态。
`velocity_request_rad_s` 与 `torque_feedforward_A` 分别是位置环输出及机械力矩前馈换算电流；
`ff_d_V/ff_q_V` 是电气 dq 解耦电压，两层前馈的单位和插入点不同。
原始数据用于核对时必须遵守各自时序，不能将下一拍命令直接与本拍端电压相减。

源码检查和告警视为错误由本例运行命令阻断；命名、职责、公式与状态归属由人工审查。
本例未接入公共测试注册表或 CI；本例定向数值证据与平台仓库 Release 结果分别记录。
实际迁移还需真实采样/角度时序、噪声与功率级测量，板上 WCET/抖动、负载及保护证据。
